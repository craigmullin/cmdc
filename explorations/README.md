# Maker's-mark explorations

Fifty monochrome vector studies generated for Alpha 0.2. These are discovery artifacts, not logo candidates or a final identity.

- 01–10: constructed monograms
- 11–20: printer's marks
- 21–30: editorial colophons
- 31–40: geometric symbols
- 41–50: abstract maker's marks

Open `contact-sheet.svg` to review the complete set. Run `node generate.mjs` from this directory to regenerate the individual files and contact sheet.
